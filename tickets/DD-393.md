# DD-393: Document The Agent-Efficient Jira Mirror

## Method

Documentation-driven development (DocsDD).

## Objective

Explain why Tira preserves Jira's work model while replacing HTTP payloads
with direct filesystem operations for coding agents.

## Acceptance criteria

- Explain the measured average payload reduction and why comment-heavy Jira
  records widen the gap.
- Record the ZEPG-1 and ZSD-1 comparison accurately.
- Explain that one Tira record read includes comments where Jira needs two
  requests.
- State clearly that Tira uses direct validated files and folders with no HTTP
  transaction layer.
- Update README, foundation documentation, Changes, and project records.
- Pass Docker metadata, full coverage, taint/perlsec, commit, and push gates.
