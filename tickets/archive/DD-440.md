# DD-440

## Title

Column-width toggle (Standard / Fit all) with a remembered choice.

## Method

Renderer-contract TDD + Browser BDD (Playwright, red-first) + visual
review on a twelve-column board.

## Problem

Owner photo (message 2976): a board with more than nine columns forces
sideways scrolling to reach hidden columns. He asked for an option to
make the container show every column, remembered in cookie or browser
storage, and reversible back to standard on the desktop.

## Design

- Every board header gains a `widther` group beside the sorter:
  `Standard` (default) and `Fit all`, styled by the same rules as the
  sort group so it reads as one control surface.
- `Fit all` sets `data-width="fit"` on the document element; CSS then
  drops the table and cell minimum widths, hides the horizontal
  overflow, and tightens header and card typography so shrunken columns
  stay legible (visual review changed `overflow-wrap:anywhere` to
  `break-word` plus a smaller card title after the first capture broke
  words mid-syllable).
- The choice is global (one board's toggle sets them all — the user
  reads the board as one surface) and persists in `localStorage` under
  `tira-column-width`, applied before `data-ready` is set so a remembered
  fit never flashes standard first. Reads and writes are wrapped: if
  storage is unavailable (private mode, blocked cookies) the board
  silently uses Standard rather than failing.
- Scoping decision, documented rather than silent: under 720px the fit
  rules revert to scrollable fixed columns — twelve columns on a phone
  would be about thirty pixels each — while the saved preference stays
  intact for the desktop.
- Works in both `-o table` and `-o browser`, since both embed the same
  script and stylesheet, and needs no server round trip.

## Acceptance

- standard is the default and keeps fixed-width columns; fit removes

  marked; every board header carries the toggle
- the choice survives a reload in both directions and applies on load;
