# DD-449

## Title

Remembered dashboard address: `--dashboard-host` and `--dashboard-port`.

## Method

Engine TDD + CLI ATDD, red-first (`t/42-dashboard-address.t`).

## Problem

Owner request, alongside asking for project-detail commands. Two of the
three things he named already exist and needed nothing:
`tira.project.update --name` renames a project, and
`tira.project.people.add` / `.deactivate` / `.activate` add and disable
people. The third did not exist: every `-o browser` run listens on
`0.0.0.0:7899` unless the address is retyped on the command line, so a
project that should stay on the loopback interface, or on a different
port, depends on remembering to say so every single time.

## Design

- The project remembers its own dashboard address in `project.yml`;
  `tira.project.update --dashboard-host HOST --dashboard-port PORT`
  sets it and `project.show` reports it.
- `--dashboard-host any` is the plain-language form of `0.0.0.0`, since
  that is how the owner phrased it ("localhost or any"), and
  `localhost` is stored as given.
- Precedence is explicit rather than incidental: an address given on the
  command line (`-o browser=localhost:8080`) wins, the project's
  remembered address is next, and `0.0.0.0:7899` remains the fallback.
  A remembered setting can therefore never surprise a caller who stated
  an address.
- Both values are validated where they are set, not where they are
  used, so a bad port is refused at the moment it is configured rather
  than the next time someone tries to serve the board.

## Acceptance

- host and port persist, are reported by `project.show`, and are used by
  `-o browser` when no address is given
- `any` maps to `0.0.0.0`; an unsupported host or an out-of-range port
  exits 2 and changes nothing
- an explicit `-o browser=host:port` still wins over the remembered one
- a project with nothing remembered still serves `0.0.0.0:7899`
- Docker tests pass; coverage `100.0%`; taint and primitive-scan gates
  pass; `cover_db` cleaned
- `SKILLS.md`, `docs/`, `Changes`, `VERSION 0.58`, tickets, BACKLOG,
  commit, and push complete
