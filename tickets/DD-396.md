# DD-396: Make Deduplicated Attachment Responses Truthful

## Method

Regression TDD + contract BDD.

## Objective

Ensure attachment add returns the reference actually retained by its target and
explicitly reports record/comment-level deduplication.

## Acceptance criteria

- A new attachment returns its stored filename, supplied filename, and
  `deduped: false`.
- Re-adding identical bytes under another name returns the existing stored
  filename, the new supplied filename, and `deduped: true`.
- Record and comment attachment lists deduplicate independently.
- Removing content and re-adding it does not falsely claim the retained
  filename changed.
- Different records may retain different filenames for identical content.
- The checklist manual explicitly states that checklist entries are retained
  and have no remove command.
- Docker tests retain 100% statement/subroutine coverage, followed by the
  taint/perlsec, documentation, commit, and push gates.
