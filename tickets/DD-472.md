# DD-472

## Title

One filter across three boards, and it finds questions.

## Epic

EPIC-469, settled point 19 (message 3147, resent as 3157).

## The owner's point

The keyword box is per board today: typing on the ticket board filters
tickets and nothing else. But a question reference belongs to the
project, not to a board — so typing `Q-234` on the ticket board should
empty the ticket board and show the epic card that question was asked
on. His words: the filter is shared, each board simply carries a copy
of the same control because that is convenient.

## Design

- **Search matches questions**: their text, their answers, and their
  references, alongside the reference, title and description it already
  matched. So `Q-007` finds the card without anybody remembering which
  card it was.
- **The filter is project-wide.** Typing in any board's box filters all
  three. Each board keeps its own input for convenience, and they stay
  in step with each other.

## Acceptance criteria

1. Searching by question text finds the card.
2. Searching by answer text finds the card.
3. Searching by question reference finds the card, from any board.
4. A discarded question is still findable, because it still happened.
5. Typing in one board's filter filters all three.
6. Every board's input shows the same text.
7. Clearing it restores all three boards.
