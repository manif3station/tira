# DD-484

## Title

Answering a question erased the questions panel.

## Source

Owner, live: "after picked the answer of a question, the whole question
and answer section on the model disappeared".

## Root cause

Every mutation in the dialog reloads the card and calls `renderCard`,
which clears the sections host and rebuilds the sections it knows
about. The questions panel was not one of them: it was appended
afterwards, by the one function that opens the dialog.

So the panel survived exactly as long as nobody touched anything.
Answering — the one thing the panel exists for — was enough to erase
it.

## The mistake behind it

I hung the panel off `showCard` rather than putting it inside the
render every path goes through. That works on the first open and
nowhere else, and it is the same shape of error as the vanishing yellow
in `DD-480`: something painted once and then wiped by the refresh that
follows. Twice in one day, from treating "it appears" as "it stays".

## Fix

The reload renders the questions too, so every path that draws a card
draws its questions. The test asserts *both* call sites, not just that
the function exists, because one call site is exactly the bug.

## Acceptance criteria

1. Answering a question leaves the panel in place, showing the answer.
2. Marking an answer likewise.
3. Every path that renders a card renders its questions.
