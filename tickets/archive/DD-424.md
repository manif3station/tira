# DD-424

## Title

Field projection on reads: `--fields` / `--exclude-fields` on show, list,
and export (CA01, CA02, CA03).

## Method

Engine TDD + CLI ATDD, red-first (`t/25-field-selection.t`).

## Problem

EPIC-424 / owner document `20-enhancement.md` (message 2941): every read
returns the complete record, so the commonest question — "what column is
this in?" — costs the whole ticket. `tira.export` is the most expensive
call and the most used; a measured session paid for all 138 full records
about forty times when nearly every call wanted `ref`, `column`, and
`sdlc_gate`.

## Design

- One projection layer in the engine (`_field_projection` /
  `_project_record`), applied by `record_show` and `record_list`;
  `export_records` inherits it through `record_list`.
- A canonical selectable-field list (every returned key including the
  computed `column`) validates names; unknown or empty names die and the
  CLI surfaces exit 2 naming the field.
- Selection always keeps `ref`; exclusion applies after selection, so
  `--fields description --exclude-fields description` leaves only `ref`.
- CLI flags `--fields` / `--exclude-fields`: comma-separated, repeatable,
  accumulating; on any command other than show/list/export they exit 2
  instead of being silently ignored.
- Stored data is never altered; without flags every read is unchanged.

## Acceptance

- `record_show` with `fields => ['column']` returns exactly `ref` +
  `column`; selected null fields stay visibly null; comma and repeat
  forms accumulate
- unknown and empty field names fail loudly on both selection and
  exclusion; a mutation given either flag exits 2 with an explanation
- list projects every record; export projects uniformly across types and
  keeps its `count`
- reads without flags return the full record exactly as before
- Docker tests pass; coverage `100.0%` statement and subroutine; taint
  and primitive-scan gates pass; `cover_db` cleaned
- `SKILLS.md` (signatures, projection contract, UC-042/UC-043 reworked,
  still exactly 100 use cases), `docs/commands.md`, `Changes`,
  `VERSION 0.35`, tickets, commit, and push complete
