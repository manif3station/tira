# DD-473

## Title

A card waiting on somebody looks like it.

## Epic

EPIC-469, settled point 12.

## The rule

Yellow means this card is waiting on somebody, in either direction:

- a question nobody has answered — waiting on the owner;
- an answer the agent has not read and marked — waiting on the agent.

It returns to its normal colour only when every question is settled:
discarded, or answered with the answer read and marked. A discarded
question settles nothing further, because it was set aside on purpose.

## The cost, stated rather than hidden

The dashboard's default is deliberately cheap: it reads filenames and
modification times and never opens a card. Knowing whether a card has
questions means reading it. So the flag is computed wherever the card
is being read anyway — with titles, or in full — and the ref-only fast
path stays as fast as it was, without a colour. That is the honest
trade: the fast path exists precisely so a big board costs nothing.

While here, the titles path read each card twice for no reason. Now
once.

## Acceptance criteria

1. A card with an unanswered question is marked as waiting.
2. A card whose answer is read but unmarked is still waiting, because
   the agent has not said whether it settles anything.
3. A card whose answers are all read and marked is not waiting.
4. A card whose only question is discarded is not waiting.
5. A card with no questions at all is not waiting.
6. The board draws a waiting card differently, and an ordinary card
   exactly as before.
7. The ref-only fast path still opens no card files.
