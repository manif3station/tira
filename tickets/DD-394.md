# DD-394: Add Record Checklists

## Method

TDD + BDD + ATDD.

## Objective

Give every SOW, epic, and ticket an ordered checklist whose entries carry an
item and user-controlled status.

## Acceptance criteria

- New and legacy records expose an empty `checklist` array by default.
- An entry has an immutable ID, item, status, creation time, and last update.
- List, add, and update commands work identically for every record type.
- Item and status are required on add; update accepts either or both.
- Human record output renders checklist items and statuses.
- README, SKILLS.md, command docs, Changes, and project records are updated.
- Docker tests retain 100% statement/subroutine coverage, followed by the
  taint/perlsec, commit, and push gates.
