# DD-454

## Title

The browser tab names the project, the board, and the card count.

## Method

Renderer-contract TDD.

## Problem

Owner request: the document title read `Tira Kanban` on every board, so
several dashboards open at once were indistinguishable in the tab strip
— the one place the name is most useful. He then refined the shape he
wanted: project, board, and the total number of cards.

## Design

- The title is `<project> :: <board> :: <cards>`, for example
  `MT5 :: Tickets :: 57`.
- The board segment names the board being shown — Statements of Work,
  Epics, or Tickets — and reads `Kanban` when all three are on the page,
  since no single board name would be true then.
- The count is what is actually rendered, so it follows the same rules
  as the page: Discard is excluded unless asked for, and a type-scoped
  dashboard counts only that type. A number in the tab that disagreed
  with the board under it would be worse than no number.
- The project name is already HTML-escaped for the heading and the same
  escaped value is reused, so a project named with markup cannot break
  out of the title.

## Acceptance
