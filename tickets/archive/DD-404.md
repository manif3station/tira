# DD-404: Auto-Refresh HTML Dashboards

## Method

Browser BDD + JavaScript timer TDD + Playwright ATDD.

## Expected happy path

- Every table dashboard schedules a page reload after five seconds by default.
- A query parameter matching `refresh=digits` selects that many seconds.
- Invalid or missing values use five seconds; zero is clamped to one second to
  prevent a continuous reload loop.
- The active interval is visible in the page and available as DOM state.
- Refresh remains fully local, embedded, and compatible with both sort modes.
