# DD-395: Prevent Silent Repeatable-Field Data Loss

## Method

Regression TDD + data-loss BDD.

## Objective

Make every accumulating record-field option append on update as documented,
while retaining explicit `--set-*` replacement behavior.

## Acceptance criteria

- `key_details`, `deliverables`, `acceptance_criteria`, `test_steps`, `bdd`,
  and `atdd` append values on every update.
- `scope.included` and `scope.excluded` also append rather than replace.
- Repeated values in one CLI call preserve their supplied order.
- Existing `--set-*` options continue to replace their complete target arrays.
- The behavior applies identically to SOWs, epics, and tickets.
- Docker tests retain 100% statement/subroutine coverage, followed by the
  taint/perlsec, documentation, commit, and push gates.
