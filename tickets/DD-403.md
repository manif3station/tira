# DD-403: Render Self-Contained Kanban Tables

## Method

BDD + HTML security TDD + Playwright ATDD.

## Expected happy path

- `tira.dashboard -o table` emits one self-contained raw HTML document with
  SOW, epic, and ticket tables stacked vertically.
- `tira.dashboard.sow|epic|ticket -o table` emits only its requested table.
- Board columns run left-to-right and cards appear beneath their column in the
  existing newest-first order.
- Embedded CSS provides a readable responsive Kanban layout; embedded JS adds
  local card selection without any network dependency.
- The visual design uses layered gradients, glass panels, type-specific accent
  colors, strong typography, depth, and polished interactive states rather
  than a plain black-and-white table.
- `--title` enriches table cards and default ref-only mode remains metadata-free.
- HTML escapes every filesystem/config/record value and table output is
  rejected outside the four dashboard commands.

## BDD and security evidence

The red gate failed 13 of 18 assertions: table output was unsupported, the
three type-specific routes did not exist, and there was no renderer, escaping,
offline contract, or scoped rejection. The implementation adds only the four
approved dashboard routes and rejects `table` for every other command.

Combined HTML contains SOW, epic, and ticket boards in that order; specific
routes contain one board. Columns use configured left-to-right order. Dynamic
refs, titles, and column names are escaped, and no link, image, iframe, URL, or
external dependency is emitted. Without `--title`, table creation performs no
JSON reads and exposes only refs plus mtime data required for browser sorting;
with it, each valid card is decoded once.

## Browser and visual evidence

Docker Playwright passed at 1440x1000 with pinned Chromium after the shared
image's Snap stub was bypassed. It proved horizontal column geometry, embedded
gradient styling, rounded glass panels, card selection, mtime/ref sorting, and
absence of external resource elements. Manual screenshot inspection confirmed
the aurora background, cyan ticket accents, readable sticky headers, compact
sort controls, card depth, and responsive horizontal overflow. Temporary HTML,
screenshot, and 300MB browser artifacts were removed after review.
