# DD-458

## Title

Column dwell and `tira.stale`: which cards have sat too long.

## Method

Engine TDD + CLI ATDD, red-first (`t/44-dwell.t`).

## Problem

EPIC-457's first piece. Everything else — escalation, the collector,
the reminder itself — needs one honest answer first: for every card,
how long has it been in the column it is in now, and which cards are
over their limit. Nothing in Tira can answer that today.

## Design

- Dwell is measured from the card's entry into its **current** column,
  per the owner's correction, which is the timestamp of the newest
  `op: move, field: column` entry in its history.
- Cards with no recorded move are **skipped**, not guessed at. History
  only began in 0.53, so 89% of one of the owner's real boards and 99%
  of another have no entry; inventing a dwell from the creation date
  would report ~190 cards as stuck for months on the first run. Each
  card joins the report naturally the first time it moves. The output
  states its `basis` so a caller can tell measured from absent.
- One pass, not one call per card: walk the board directories once to
  learn each card's current column from its parent directory, then read
  each journal **backwards**, testing each line with a string match
  before decoding it, and stop at the first column move. Measured 2.6ms
  for 100 cards against 265ms for the per-card API route and ~14s for
  the per-card CLI route; the reverse scan also stays flat as journals
  grow, where a forward scan degrades.
- The last move's `after` is **not** required to equal the card's
  current column: `column_rename` and `column_remove` relocate cards
  without journaling, so demanding a match would turn both into false
  "never moved" answers.
- Timestamps are parsed defensively. One of the owner's boards stores
  `created_at` as a raw epoch integer, which the strict ISO parser
  rejects outright; an unparseable stamp yields `basis: unknown`
  instead of taking the command down.
- `--older-than MINUTES` filters to cards past that age, which is what
  the collector will ask for.

## Acceptance

- dwell measured from the last column move; a card that has never moved
  is skipped and reported as such, never invented
- a card moved back and forth reports its most recent entry
- a renamed or removed column does not break the reading
- unparseable timestamps degrade to `unknown` rather than dying
- `--older-than` filters correctly; the command works across all three
  boards in one call
- Docker tests pass; coverage `100.0%`; taint gate passes; `cover_db`
  cleaned
- `SKILLS.md`, `docs/`, `Changes`, `VERSION 0.65`, tickets, BACKLOG,
  commit, and push complete
