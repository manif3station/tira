# DD-430

## Title

Comment windows and comment/attachment metadata reads (CA10, CA11, CA12).

## Method

Engine TDD + CLI ATDD, red-first (`t/31-comment-attachment-meta.t`).

## Problem

EPIC-424: an epic accumulates a hundred comments and reading the newest
requires all of them; a watcher needs to know a comment appeared and who
wrote it without paying for the text; checking that evidence exists
should not require the records.

## Design

- `comment_list` consumes its own options before delegating to
  `record_show`, so sub-options can never be misread as record options:
  `last`/`first` windows over the newest-last storage order (mutually
  exclusive, negative refused, zero = `{count}`), `since` against the
  comment's own stamps, `meta_only` (id, author, format, stamps,
  `body_length`, `attachment_count`), comment-level `fields` with `id`
  always kept (`body` with meta-only refused), `count`.
- Record reads accept `meta_only` to strip embedded comment bodies —
  board-wide comment detection through the same export call.
- `attachment_list --ref` enriches under meta/fields/since/count: stored
  filename (already extension-bearing — a red-loop discovery), real byte
  size from the store, content type from the extension map (moved into
  the engine as the single source of truth, the CLI now delegating),
  `added_at`, `sha`; newest-first; envelope `count` + `total_size`.
  These options without `--ref` exit 2. Deduplication status is not
  derivable post-hoc (supplied names are not retained) and is recorded
  here as out of scope rather than silently skipped.
- Computed `attachment_count` joins the selectable record fields.
- Loop note: two block-versus-hashref parses (`+{` fixes) were caught
  red and now sit under permanent assertions.

## Acceptance

- windows, meta, fields, since, count behave per tests on both comments
  and attachments; ids/shas always kept; contradictions and unknown
  names exit 2; oversize windows safe; zero windows report counts
- record- and export-level `--meta-only` strip bodies everywhere
- `attachment_count` selectable; guards exit 2 with named scope
- Docker tests pass; coverage `100.0%`; taint gate passes; `cover_db`
  cleaned
- `SKILLS.md` (signatures, contract, UC-090 reworked, exactly 100 use
  cases), `docs/commands.md`, `Changes`, `VERSION 0.41`, tickets,
  commit, and push complete
