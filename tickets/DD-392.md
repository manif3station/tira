# DD-392: Harden UTF-8 Comments And Repair Legacy JSON

## Method

TDD + security BDD.

## Objective

Make UTF-8 handling explicit at every Tira CLI and JSON boundary, prove long
currency-bearing comments, and recover records written by the former mixed
byte/character implementation.

## Acceptance criteria

- Decode CLI argv and comment-file text strictly as UTF-8.
- Encode canonical JSON persistence and structured CLI output explicitly as
  UTF-8 bytes.
- Preserve attachment retrieval as byte-for-byte raw output.
- Round-trip a comment longer than 36 KB containing `£` without warnings.
- Recover isolated legacy non-UTF-8 bytes without replacing the intended
  character, then persist valid UTF-8 on the next record mutation.
- Pass Docker functional, 100% coverage, taint/perlsec, and installed command
  gates.
- Update required documentation, commit, and attempt the mandatory push.
