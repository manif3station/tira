# DD-389: Implement The Complete 100-Use-Case Tira CLI Contract

## Method

TDD + BDD + ATDD.

## Objective

Turn every command and workflow documented in `SKILLS.md` into shipped,
executable Tira behavior. Completion requires all UC-001 through UC-100 to be
implemented; availability labels may not remain specification-only.

## Acceptance criteria

- All project, board, column, record, hierarchy, subitem, typed-link,
  assignment, comment, attachment, evidence, gate, search, and dashboard
  commands are dispatched by Developer Dashboard.
- Documented required, optional, repeatable, mutually exclusive, default, and
  precedence behavior is executable and tested.
- Bidirectional and multi-file changes are validated, locked, atomic, and
  rollback-safe.
- No record-delete command exists; Discard and restoration remain reversible.
- Attachment content is SHA-256 addressed, deletion is logged, and raw
  retrieval never discloses managed storage paths (strengthened by DD-391).
- Docker tests achieve 100% statement and subroutine coverage.
- The final functional gate is followed by the perlsec/taint security gate.
- README, `docs/`, Changes, `SKILLS.md`, and testing evidence match proven
  behavior before commit and push.
