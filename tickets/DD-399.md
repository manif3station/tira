# DD-399: Make Hierarchy Reads Truthful

## Method

Problem-solving regression TDD + read-path consistency BDD.

## Expected happy path

- Hierarchy show returns the same record fields as the corresponding record
  show, plus its immediate or recursive children.
- Human output includes the actual description, assignee, priority, and child
  references without warnings.
- An unknown reference exits 2 and never resembles an empty valid record.

## Problem statement and reproduction

Release 0.10 returns a deliberately sparse hierarchy node containing only ref,
type, title, and children. The generic human record renderer then treats absent
fields as real values, emits uninitialized-value warnings, and presents false
empty metadata. Reproduce through the installed CLI by creating an assigned,
described, prioritised epic with linked tickets, then compare
`tira.hierarchy.show --ref REF -o human` and recursive JSON with
`tira.epic.show --ref REF -o json`. Also request a nonexistent ref and record
its exit status.

## Before and after evidence

Installed 0.10 reproduced the report in a disposable project. Hierarchy human
output exited 0 but wrote three uninitialized-value warnings and displayed no
description, assignee, priority, or timestamps. Recursive JSON contained only
`children`, `ref`, `title`, and `type`; direct epic show contained the full
description, `zenbot`, priority 3, and all three ticket refs. An unknown ref
exited 2.

The regression gate then failed 10 new consistency assertions. After the fix,
the identical project and refs produced status 0 with empty stderr, the full
description, resolved Zenbot assignee, Medium priority, and all three children.
Recursive JSON retained the root's complete fields and complete child records.
The unknown ref still exited 2 with its structured not-found error.

## Root cause and guard

`hierarchy_show` read the complete record correctly, then replaced it with a
four-field synthetic node. The shared Markdown renderer reasonably expected a
record and interpreted the discarded keys as empty. The fix retains the record
and overlays only `children`; Markdown renders that array explicitly.
`t/05-collaboration.t` guards engine-level complete recursive nodes, while
`t/07-command-matrix.t` guards JSON agreement, warning-free human output,
children, and unresolved-ref status.
