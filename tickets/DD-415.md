# DD-415

## Title

True attachment list with legacy timestamp backfill.

## Method

Engine TDD + Browser BDD, driven by the owner's screenshot of a real
board (Telegram message 2888).

## Problem

The 0.22 attachment work stamped only new uploads and rendered chips in a
wrapping cloud. On a real project: long filenames clipped at the edge,
two chips per row, and every pre-0.22 attachment showed an em-dash so the
newest-first sort looked broken.

## Resolution

- Vertical one-per-row list: filename left, date right-aligned, delete at
  the row end; linkage chips keep their inline form.
- `record_show` backfills missing `added_at` from the deduplicated store
  file's mtime (when that content first arrived), persisting on the next
  record mutation — the same read-repair policy as the legacy UTF-8 fix.
  Only references whose stored file was physically removed keep the dash.
- Guards: engine test pins the backfill to a utime-controlled epoch; the
  permanent browser scenario asserts row geometry (same x, stacked y,
  ≥95% strip width).

## Status

Done — shipped in 0.26.
