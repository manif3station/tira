# DD-435

## Title

Compact JSON by default (CA14).

## Method

Formatter TDD, red-first (`t/36-compact-json.t`), with the existing
foundation contract updated deliberately.

## Problem

EPIC-424: pretty-printed JSON spends a meaningful fraction of its bytes
on whitespace. For a person that is worth paying; for an agent it is
pure cost.

## Design

- `-o json` emits `JSON::PP->new->canonical->encode` plus a trailing
  newline: one line, stable key order (which is what makes hashing and
  diffing possible), raw unescaped UTF-8.
- `-o json-pretty` is the previous pretty form, byte-for-byte.
- Formats stay presentation-only; the structured-error-to-stderr rule
  is now pinned by a test so stdout can never carry a corrupted
  payload. The live dashboard `/data` payload shrinks as a side effect
  since it renders through the same formatter.
- `t/00-foundation.t`'s "JSON output is pretty printed" assertions were
  the old contract and were updated to the new one — a deliberate,
  owner-approved change recorded here, not a test worked around.

## Acceptance

- compact default: one line, stable across calls, smaller than pretty,
  information-identical, `\x{A3}` raw not `£`
- `json-pretty` available; unknown formats still die; CLI failure keeps
  stdout empty with the structured error on stderr
- Docker tests pass; coverage `100.0%`; taint gate passes; `cover_db`
  cleaned
- `SKILLS.md` (output contract, UC-013 reworked, exactly 100 use
  cases), `docs/commands.md`, `Changes`, `VERSION 0.46`, tickets,
  commit, and push complete
