# DD-499

## Title

A question set aside was still offering somewhere to drop a file.

## Source

Owner: for a discarded question, do not show the attachment area the
way an active one does. Show files only if there are any. If there are
none there is no point showing anything, since it is effectively
deleted and will not be updated.

## The point

The drop zone is an invitation. On a question nobody will ever act on
again it invites something that cannot happen — and a control that
does nothing teaches people to distrust the ones that do.

Files already on a discarded question still show, because they still
happened and somebody reading the history may want them. A discarded
question with no files now shows nothing but the question, struck
through, and when it was set aside.

## Verified by looking

Three questions on one card — live, discarded with a file, discarded
with none:

    Q-001 new        drop=true  files=0
    Q-002 discarded  drop=false files=1
    Q-003 discarded  drop=false files=0
