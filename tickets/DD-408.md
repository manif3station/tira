# DD-408

## Title

Make list fields editable in the card dialog.

## Method

Engine/CLI TDD + HTTP ATDD + Browser BDD (Playwright)

## Problem

The dialog edits single-value fields, comments, and attachments, but the
list fields — labels, affects versions, key details, deliverables, scope
included/excluded, acceptance criteria, test steps, BDD, ATDD, and checklist
items — remain CLI-only. Approved by the owner via Telegram ("Do it",
message 2832, 2026-08-06) after the gap was disclosed.

## Scope sketch (to be planned in detail before build)

- per-item add/edit/remove controls on each list section, routed through the
  engine's existing append/replace and checklist update semantics
- checklist items keep their immutable CHK ids and retained-not-deleted rule
  (status/item edits only, no removal control)
- linkage stays read-only in the dialog (structural commands remain CLI)

## Status

Planned — next after the DD-407 release.
