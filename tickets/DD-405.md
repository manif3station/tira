# DD-405: Serve Live Dashboards Through Dancer2

## Method

Server BDD + CLI TDD + HTTP ATDD.

## Expected happy path

- `-o browser` starts the supplied Dancer2 PSGI application on
  `0.0.0.0:7899`.
- `-o browser=HOST` uses an approved host with port 7899.
- `-o browser=HOST:PORT` uses an approved host and valid TCP port.
- The root route returns the self-contained board shell and `/data` returns the
  same complete records as dashboard JSON output.
- Requests such as `/?refresh=30` drive AJAX polling; cards move in place and
  the document is not reloaded.
- Clicking a card opens a full-record dialog, and last-updated changes only
  after fresh JSON is applied.
- Unsupported hosts, malformed endpoints, and ports outside 1-65535 fail
  safely before startup.
