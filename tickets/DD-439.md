# DD-439

## Title

Default dashboard refresh interval 60 seconds.

## Method

Renderer-contract TDD + Browser BDD (Playwright).

## Problem

Owner instruction: change the default live-refresh interval to 60
seconds. Five seconds was chosen when the board was the only live
surface; with DD-438's repaint-only-on-change cycle the frequent poll
buys little and costs a request per card view per five seconds.

## Design

- Both places that carry the default move together: the header badge
  text (`Refresh 60s`) and the script's fallback when `?refresh` is
  missing or invalid. The explicit `?refresh=N` override, the
  positive-integer validation, and the one-second clamp are unchanged.
- t/16 pins the badge text and the script fallback so a future edit
  cannot silently change the default in one place only.
- The Playwright mobile pass now loads `?refresh=2` explicitly: the
  refresh guards (quiet-cycle fetch budget, DOM stability, editor race)
  test per-cycle behaviour, not the length of the default, and asking
  for a short interval keeps them fast and honest. The quiet-cycle
  budget moved to 4 reads across roughly three 2-second cycles —
  post-fix costs one comparison read per cycle, pre-fix cost four.

## Acceptance

- default badge and script fallback both read 60; `?refresh=30` still

- Docker tests pass; coverage `100.0%`; taint gate passes; `cover_db`
  cleaned; Playwright ×3 green with the refresh guards intact
- `README.md`, `SKILLS.md`, `Changes`, `VERSION 0.50`, tickets,
