# DD-474

## Title

The Discard column nobody could see.

## Source

Owner, message 3145, noticed while filing something else: every board
is created with a Backlog and a Discard, he saw Backlog on the
dashboard and never Discard. He asked for it to be its own ticket
rather than folded into the question work, which is why it waited.

## The defect

Discarding a card removed it from the only view he actually uses. The
work was still there on disk, and `--include-discard` would show it,
but nobody thinks to pass a flag for something they do not know is
missing. From the board's point of view, discarded work simply
vanished.

## Fix

A board a person is looking at — table or browser — shows the Discard
column. The ref-only listing an agent queries does not, because it
exists to be cheap and an agent asking for a board's live work should
not pay for cards nobody wants. `--include-discard` still forces it
either way, and the machine formats are unchanged unless asked.

Drawn faded and marked as set aside, so it reads as an archive rather
than as more work outstanding. A board that looks busier than it is
would be its own kind of lie.

## Acceptance criteria

1. The table and browser boards show Discard and the cards in it.
2. It is visibly distinguishable from live columns.
3. The ref-only board still leaves it out.
4. `--include-discard` still works, and machine output is unchanged
   unless asked.
