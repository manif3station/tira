# DD-426

## Title

Changed-since filtering on show, list, and export (CA04).

## Method

Engine TDD + CLI ATDD, red-first (`t/27-changed-since.t`).

## Problem

EPIC-424: a watcher polls the whole board every five minutes to discover
what changed — 288 full downloads a day on a quiet board. The
information needed is a delta; the tool could only supply a snapshot.

## Design

- `_epoch_of_datetime` parses `Z`, `±HH:MM`, and the `±HHMM` the default
  clock writes; missing offsets read as UTC; anything else dies, so a
  malformed threshold can never silently mean "everything".
- `_changed_since` compares instants; a record whose stored stamp cannot
  be parsed is treated as changed — since may skip quiet records but
  must never hide one.
- `record_show` returns `{}` for an unchanged record; `record_list`
  filters before projection; `export_records` captures `now` from the
  clock before scanning and adds it to the envelope, so chained polls
  have no gaps (boundary-second repeats are the safe side).
- CLI `--since` joins the read-options guard: allowed on show, list, and
  export; exit 2 anywhere else.

## Acceptance

- inclusive instant comparison across offsets (a `+01:00` threshold
  matches the equivalent `Z` stamp); future thresholds empty with exit
  0; malformed thresholds exit 2 naming the failure
- export envelope carries `now` only when `--since` is used; count
  reflects the filtered set; composes with `--fields`
- unreadable stored stamps are returned, never hidden
- Docker tests pass; coverage `100.0%`; taint gate passes; `cover_db`
  cleaned
- `SKILLS.md` (signatures, since contract, UC-043 extended, exactly 100
  use cases), `docs/commands.md`, `Changes`, `VERSION 0.37`, tickets,
  commit, and push complete
