# DD-405: Serve Live Dashboards Through Dancer2

## Method

Server BDD + CLI TDD + HTTP ATDD.

## Expected happy path

- `-o browser` starts the supplied Dancer2 PSGI application on
  `0.0.0.0:7899`.
- `-o browser=HOST` uses an approved host with port 7899.
- `-o browser=HOST:PORT` uses an approved host and valid TCP port.
- The root route returns the self-contained board shell; `/data` returns only
  card placement and optional titles, while `/record` returns one complete
  record on demand.
- Requests such as `/?refresh=30` drive AJAX polling; cards move in place and
  the document is not reloaded.
- Clicking a card makes one `/record` AJAX request and opens a full-record
  dialog; placement polling never carries full record fields.
- Dragging a card calls `/move`, physically moving its JSON file to the target
  column, then refreshes lightweight placement data.
- Dropping a card on another column calls the real record move and then refreshes
  its lightweight placement.
- Unsupported hosts, malformed endpoints, and ports outside 1-65535 fail
  safely before startup.
