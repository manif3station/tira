# DD-455

## Title

Select several cards and move them together; full-width board in Fit.

## Method

Browser BDD (Playwright) with a red check against the previous
stylesheet, plus renderer-contract assertions and a visual review.

## Problem

Owner request: shift-click to select several cards and drag them to
another column in one gesture; with a selection active, a plain click on
any card clears the selection and opens that card. Separately, Fit mode
should drop the board's side margins so more of the board is visible.

## Design

- Selection lives in a set of refs, not in the DOM alone, so it survives
  the live refresh that rebuilds every card element — the marks are
  re-applied after each rebuild rather than lost every minute.
- Shift-click toggles selection and never opens the dialog; a plain
  click clears any selection first and then opens the card, which is
  exactly the behaviour asked for and also the escape hatch when a
  selection is no longer wanted.
- Shift is excluded from arming a drag, so selecting cannot start one by
  accident.
- A drag that begins on a *selected* card carries the whole selection;
  a drag on an unselected card carries only itself. The ghost shows the
  batch size, so a five-card move is visibly a five-card move before it
  is released.
- Every card in the batch posts the same validated `/move` the single
  drag always used — no bulk endpoint, no new server semantics — and the
  selection clears once they all succeed. A failure leaves the selection
  alone so the move can be retried.
- Fit mode drops the shell's side gutters and the board's horizontal
  padding to zero, which on a thirteen-column board recovers roughly
  60px of width — 81px columns become 86px.

## Acceptance

- shift-click selects and deselects without opening the dialog
- dragging a selection posts one move per selected card with the right
  refs and column, and clears the selection afterwards
- the ghost shows the batch size
- a plain click clears the selection and opens that card
- selection survives a refresh cycle
- Fit mode board runs edge to edge; Standard is unchanged
- Docker tests pass; coverage `100.0%`; taint gate passes; fixtures and
  `cover_db` cleaned; browser guards green ×3
- `Changes`, `VERSION 0.63`, tickets, BACKLOG, commit, and push complete
