# DD-409

## Title

Editable linkage in the card dialog, section-label edit pencils for long
texts, and full mobile responsiveness.

## Method

Engine-provider TDD + HTTP ATDD + Browser BDD (Playwright, desktop and
mobile viewports)

## Problem

Owner instructions (Telegram message 2852, 2026-08-06): linkage must be
editable from the popup like everything else; the Description edit pencil
should sit next to the section label instead of the value; and the
dashboard must work properly on an iPhone Pro Max class screen.

## Design

- Linkage edits reuse the transactional engine commands — never raw record
  writes: `hierarchy_link`/`hierarchy_unlink` for SOW-epic and epic-ticket
  parents and children, `subitem_link`/`subitem_unlink` for sub-item
  parents and children, `link_add`/`link_remove` for typed links with
  reciprocals, and `link_type_list` to feed the type dropdown.
- New routes: GET `/link-types`; POST `/hierarchy/link`,
  `/hierarchy/unlink`, `/subitem/link`, `/subitem/unlink`, `/link/add`,
  `/link/remove` — all through the structured-422 mutation wrapper.
- The dialog's Linkage section becomes interactive: parent rows show the
  ref with Link/Unlink controls, children rows list refs with per-entry
  Unlink plus an add box, and typed links get a type dropdown fed by
  `/link-types` with per-entry Remove.
- Long-text sections (Description, Problem/Feature, Solution Needed) move
  their edit pencil into the section heading.
- A small-screen media query makes the dialog near-fullscreen, stacks the
  details grid to one column, and keeps board columns usable; a dedicated
  mobile-viewport Playwright pass proves no horizontal overflow at
  iPhone Pro Max width with the dialog open.

## Acceptance

- every linkage field edits from the dialog through the correct engine
  command, with engine validation errors (wrong type pairing, unknown ref,
  unknown link type) surfacing inside the dialog
- typed-link creation offers the project's configured outward and inward
  names; removal removes the reciprocal too (engine semantics)
- the Description pencil renders inside the section heading, likewise
  Problem/Feature and Solution Needed; editing still posts the same
  `/update` payloads
- at 430px viewport width the page shows no horizontal overflow, the
  dialog fills the screen usably, and the details grid stacks
- Docker tests pass; coverage `100.0%` statement and subroutine; taint and
  primitive-scan gates pass; `cover_db` cleaned
- Playwright proves the linkage add/remove payloads, the heading pencil
  location, and the mobile pass; visual review on both viewports
- `README.md`, `docs/`, `SKILLS.md`, `Changes`, `VERSION 0.20`, tickets,
  commit, and push complete from the `tira` repository
