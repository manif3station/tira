# DD-475

## Title

Don't chase an agent for a card that is waiting on you.

## Epic

EPIC-469, settled points 5, 6, 7, 8 and 16.

## The rule

While a card has a question nobody has answered, it is not in the
agent's hands — it is in the owner's. Chasing the agent for it is
chasing the wrong person, and it is the fastest way to teach an agent
that the reminders are noise.

So:

- **A card with an unanswered question is not reported as stale.**
- **Its dwell clock stops.** When the last question is answered, dwell
  runs from that moment, not from the move that put the card in its
  column — otherwise answering after three days makes the card
  instantly overdue and blames the agent for the owner's delay.
- **Escalation resets to level 1**, because the agent was blocked
  rather than idle.
- **An all-clear goes to the agent** saying every question on the card
  is answered and it is back with them.
- **The exemption ends the moment the owner answers the last question**,
  not when the agent marks the answers. Waiting for its marks would let
  an agent dodge reminders forever by never acknowledging anything.

## Design

The level is counted, not stored, so the reset is a marker row that
counting starts after — the same trick that makes a card move reset
escalation for free. Notification rows gain a `kind`, so an all-clear
is recorded distinctly from a reminder and neither is mistaken for the
other. Old databases are migrated in place.

Whether an all-clear is owed is derived too: the card's questions are
all answered, and the newest answer is newer than the last all-clear
sent for it. Nothing to keep in step.

## Acceptance criteria

1. A card with an unanswered question is never reported as stale.
2. Answering the last question puts it back in scope.
3. Dwell then runs from the answer, not from the move.
4. Escalation restarts at level 1 after the block clears.
5. An all-clear is owed once, and not again until new questions are
   asked and answered.
6. Marking answers is not required for any of this.
7. A database written before this release still works.
