# DD-420

## Title

Escape layering, viewer reset on close, and live refresh of the open
dialog.

## Problem-Solving Loop record

1. **Expected:** Escape closes the attachment preview first and the
   dialog second; a reopened dialog always shows the clicked card; an
   open dialog reflects changes made elsewhere.
2. **Problem:** owner report (2915): Escape killed the whole modal from
   the preview; the next card then showed old content; remote edits
   never appeared.
3. **Root cause:** the dialog's native cancel path had no cleanup, so
   the viewer overlay survived and painted the previous attachment over
   the next card — the "old content" was the stale viewer layer. And no
   code path ever re-read an open dialog's record.
6. **Fix:** `cancel` intercept (viewer-first Escape), `close` reset, and
   a refresh-cycle dialog reload guarded so active editors, focused form
   fields, or the open composer suppress it — typing is never destroyed.
7-8. **Re-run/guards:** two-step Escape, fresh-card reopen, and a
   real-cycle live update are permanent Playwright assertions.

## Status

Done — shipped in 0.31.
