# DD-391: Remove Attachment Path Disclosure

## Method

TDD + security BDD.

## Objective

Make attachment storage location strictly private by removing every supported
path-retrieval form while preserving raw content retrieval.

## Acceptance criteria

- Reject the former path output selection as unsupported before emitting
  content; ordinary raw retrieval remains unchanged.
- Never include the managed attachment path in successful or failed output.
- Preserve raw content retrieval and deleted-marker status behavior.
- Remove path retrieval from the agent manual and user documentation.
- Pass Docker functional, 100% coverage, and taint/perlsec gates.
- Update required documentation, commit, and attempt the mandatory push.
